# Glossar

## Bezeichnungen und Zahlen

Was du auf dem Bild, in der Farbliste und in den Rezepten liest.

| Bezeichnung | Englisch | Bedeutung |
|---|---|---|
| 0,8 | 0.8 | Der Abstand zwischen Ziel und Mischung, in Schritten, die das Auge gerade noch unterscheidet (siehe Treffer). |
| 1, 2 (auf einer Schicht) | 1, 2 | Schichten, eine Schicht allein gezeigt: wie viele Lasuren eine Fläche bekommt. |
| 1:9 mit Wasser | 1:9 with water | Schichten: ein Teil Farbe auf neun Teile Wasser, mit einem Vergleich wie „wie Kaffee“. |
| 3 x P 672 | 3 x P 672 | Drei Teile der Farbe 672 aus dem Näpfchen. Die Teile zählst du in Pinselladungen. |
| 52 in 20 Mischungen | 52 in 20 mixes | 52 Farben auf dem Papier, aus 20 Pfützen in verschiedenen Lasuren. |
| 6L, 6R | 6L, 6R | Mischung 6 als leichte (L) oder kräftige Lasur (R). Die Zahl ist die Mischung, der Buchstabe die Wassermenge. |
| A1, A2 | A1, A2 | Schichten: Akzente, nummeriert in der Reihenfolge, in der sie gemalt werden, ganz zuletzt. |
| C | C, concentrated | Konzentriert: Farbe, die kaum noch fließt. |
| L | L, light | Leichte Lasur. |
| M | M, medium | Mittlere Lasur. |
| P, T, P/T | P, T, P/T | Näpfchen (pan), Tube oder beides: in welcher Form du eine Farbe besitzt. |
| R | R, rich | Kräftige Lasur: wenig Wasser, starke Farbe. |
| W | W, very watery | Sehr wässrig: kaum mehr als gefärbtes Wasser. |
| W1 bis C5 | W1 to C5 | Bei Tonwerten feinere Wasserstufen innerhalb jeder Stufe. |

## In der App

| Begriff | Englisch | Bedeutung |
|---|---|---|
| Akzent | Accent | Schichten: eine kräftige Lasur auf kleinen Flächen, zuletzt gemalt, zuerst für eine Farbe, die die Schichten nicht treffen, dann für die dunklen Stellen. |
| Alle Details | Full breakdown | Ziel und Mischung nebeneinander, die Farbe von Hand und alle Rezepte einer Farbe. |
| Ausschnitt | Detail | Ein Teil des Bildes, als eigenes Bild analysiert. Pro. |
| Auto | Auto | Die App wählt die Farben, die zum Bild passen, aus den Kästen mit **Für „Auto“ nutzen**. |
| Deine Mischung | Your mix | Die Farbe, die das Rezept auf weißem Papier ergibt. |
| Details | Details | Die Einstellung, ob die Mischungen feine Abstufungen im ganzen Bild geben (hoch) oder kleinen Flächen eines anderen Farbtons (niedrig). |
| Farben | Colours | Die Einstellung für die Anzahl der Mischungen und ihre Liste. |
| Farbfläche | Colour area | Eine Form des Bildes, die eine Lasur einer Mischung bekommt. |
| Farbkasten | Paint box | Eine benannte Sammlung deiner Farben, zum Beispiel deine Näpfchen oder ein Reiseset. |
| Flächen vereinfachen | Simplify areas | Fasst kleine Formen zu größeren, ruhigeren zusammen. |
| Fotofarbe | Photo colour | Die Ansicht jeder Fläche in der durchschnittlichen Farbe des Fotos dort. |
| Geometrisch | Geometric | Flächen als Vielecke mit geraden Kanten statt ihres organischen Umrisses. |
| Gemischte Farbe | Mixed paint | Die Ansicht dessen, was deine Farben erreichen. |
| Geschichtete Farbe | Layered paint | Schichten: die Ansicht des fertigen Bildes, alle Schichten zusammen. |
| Grundfarbe | Base paint | Schichten: eine Farbe, die eine eigene Schicht bekommt. |
| Lasur | Wash | Eine Mischung in einer Wasserstufe. |
| Lasur, Durchgang | Coat | Schichten: ein Auftrag der Lasur einer Schicht. Eine Fläche kann dieselbe Lasur ein-, zwei- oder dreimal bekommen. |
| Max. Farben | Max. paints | Aus wie vielen Farben eine Mischung bestehen darf: einer, zwei oder drei. |
| Max. Lasuren | Max. coats | Schichten: wie oft eine Lasur über sich selbst gemalt werden darf. |
| Mischung | Mix | Eine Pfütze Farbe auf der Palette, mit einer Nummer. Sie kann in mehreren Lasuren gemalt werden. |
| Organisch | Organic | Flächen, die den Umrissen des Fotos folgen. |
| Palette | Palette | Die Farben, aus denen ein Bild gemischt wird. Sie wird mit dem Bild gesichert. |
| Raster | Grid | Quadratische Felder über dem Bild, um es Feld für Feld auf Papier zu übertragen. |
| Rezept | Recipe | Welche Farben, in wie vielen Teilen, mit wie viel Wasser, für eine Farbe. |
| Schicht | Layer | Schichten: die Lasur einer Grundfarbe, über die trockenen Schichten davor gemalt. |
| Schichten | Layer mode | Die Methode, ein paar Lasuren übereinander zu legen, statt jede Farbe zu mischen. |
| Tonwerte | Values | Das Bild in Grau analysiert; jeder Tonwert wird mit einer Farbe der Palette gemalt. |
| Treffer | Match quality | Wie nah ein Rezept seinem Ziel kommt: sehr gut (unter 2), gut (unter 5), mäßig (unter 10), grob (ab 10). Englisch: excellent, good, fair, rough. |
| Überlagerung | Overlay | Die Ansicht des Fotos in halber Stärke über der Farbe. |
| Ziel | Target | Die Farbe, die das Foto an einer Stelle verlangt. |

## Malbegriffe

| Begriff | Englisch | Bedeutung |
|---|---|---|
| Auswaschen, Anlösen | Lifting | Farbe mit feuchtem Pinsel oder Tuch vom Papier nehmen; auch das ungewollte Lösen einer trockenen Schicht durch die nächste. |
| Blumenkohlrand | Backrun, bloom | Ein ausgefranster Rand, wo nassere Farbe in eine schon antrocknende Lasur zurückläuft. |
| Deckend | Opaque | Eine Farbe, die das darunter abdeckt, statt es zu filtern. |
| Färbend | Staining | Eine Farbe, die in die Papierfasern zieht und sich trocken kaum noch auswaschen lässt. |
| Granulation | Granulation | Pigmentteilchen, die sich in die Körnung des Papiers setzen und Struktur geben. |
| Kante, hart, weich, verloren | Edge, hard, soft, lost | Die Grenze einer Form: auf trockenem Papier gemalt, vertrieben oder in die Nachbarform aufgelöst. |
| Komplementärfarben | Complementary colours | Farben, die sich im Farbkreis gegenüberliegen; gemischt neutralisieren sie sich. |
| Lasur | Glaze | Eine dünne transparente Farbschicht über einer trockenen. |
| Leimung | Sizing | Die Gelatine oder andere Leimung in und auf dem Papier, die verhindert, dass die Farbe wie Tinte im Löschpapier einsinkt. |
| Matt, kaltgepresst | Cold-pressed, NOT | Papier mit mittlerer Körnung, die übliche Wahl für Aquarell. |
| Nass auf trocken | Wet-on-dry | Farbe auf trockenem Papier, für klare Kanten. |
| Nass in nass | Wet-in-wet | Farbe in eine noch nasse Lasur oder auf nasses Papier, sodass sie weich verläuft. |
| Purton | Masstone | Die Farbe einer Farbe in voller Stärke. |
| Rau, Torchon | Rough | Papier mit starker Körnung. |
| Satiniert, heißgepresst | Hot-pressed | Glattes Papier, gut für feine Einzelheiten, schwieriger für gleichmäßige Lasuren. |
| Schmutz | Mud | Eine stumpfe, leblose Mischung, meist aus zu vielen Farben oder vom Arbeiten in eine antrocknende Lasur. |
| Tonwert | Value | Wie hell oder dunkel eine Farbe ist, unabhängig vom Farbton. |
| Transparent, lasierend | Transparent | Eine Farbe, die das Licht bis zum Papier durchlässt. |
| Unterton | Undertone | Die Farbe einer Farbe in dünner Lasur, die von ihrem Purton abweichen kann. |
